# 官方插件 {#official-plugins}

Kokkoro 官方插件保存在框架仓库中，与 Kokkoro v3 一同维护。安装后重新启动项目，Kokkoro 会自动加载这些插件。

- **[一言](/plugin/hitokoto)**：随机获取动画、文学、诗词等类型的语句。
- **[疯狂星期四](/plugin/kfc)**：响应疯狂星期四指令和相关关键词。
- **[代码执行](/plugin/eval)**：在聊天中执行 JavaScript 或 TypeScript 代码。
- **[SauceNAO 图片搜索](/plugin/saucenao)**：通过 SauceNAO 查找图片来源。
- **[Open Graph 预览图](/plugin/og)**：读取网页声明的 Open Graph 预览图并发送到当前会话。

更多插件可以在 [插件市场](/plugin/market) 中查找。Kokkoro v1、v2 及更早版本提供过的插件参阅 [旧版插件](/plugin/legacy)。
