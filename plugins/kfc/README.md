# kokkoro-plugin-kfc

vivo 50

## 安装

```shell
bun add kokkoro-plugin-kfc
```

## 指令

```text
/疯狂星期四
```

发送「/疯狂星期四」，插件会随机返回一条疯狂星期四文案。

## 快捷方式

消息中包含以下任意一类关键词时，插件也会随机返回一条疯狂星期四文案。

- 付款梗，例如「V我50」、「微我五十」或「vivo50」
- 肯德基，例如「肯德基」或「KFC」
- 星期四，例如「周四」、「星期四」、「木曜日」或「Thursday」

北京时间每周四，消息中出现「麦当劳」、「金拱门」、「华莱士」、「汉堡王」、「德克士」或「塔斯汀」时，也会随机返回一条疯狂星期四文案。

群聊需要开启「获取群内全部消息」权限。
